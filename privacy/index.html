隐私政策

生效及更新日期：2026 年 10 月 31 日 · 适用插件版本：1.6.0

这份政策说明 Agent Leaderboard 如何处理你使用 Chrome 搜索助手和官网时涉及的数据。

插件的搜索与筛选在你的设备上完成，插件收藏保存在当前浏览器。插件无需注册账号。插件不向开发者上传搜索词或收藏，不读取浏览历史、Cookie 或整页正文，也不包含广告或分析追踪代码。目录更新会产生必要的网络请求。官网另有可选的 GitHub 登录与云收藏：站点配置并由你主动登录后，网站收藏通过 Supabase 按账号保存。

适用范围

本政策适用于由 Jiancheng Pan（GitHub：jaychempan）维护的 Agent Leaderboard Chrome 插件，以及 agentskills.media 官网。插件用于搜索、筛选、收藏公开的 AI 工具仓库，并复制仓库链接和安装提示。

插件与官网使用各自的浏览器存储。插件收藏不与官网或其他设备同步；官网在配置云服务并登录后，可以在同一 GitHub 账号的设备之间同步网站收藏。你主动打开的 GitHub 仓库、其他外部网站和 AI 编程服务，适用各自的隐私政策。

插件在本地处理什么

搜索词、筛选条件和主动选择的文字
你在插件或地址栏中输入的搜索词，以及主动使用右键搜索时选中的文字，仅用于本地目录检索。插件不自动扫描网页。当前搜索与筛选状态保存在浏览器会话存储中；右键请求在接收后移除，不发送到搜索服务器。地址栏搜索或备用搜索页面可能将关键词放在本地 chrome-extension:// 页面地址中。
收藏的仓库
仓库标识及收藏时的公开仓库资料保存在插件本地存储中，以显示插件收藏列表。插件没有收藏账户或云同步；官网的可选云收藏不读取插件存储。
偏好设置和目录缓存
语言、主题、公开目录缓存与最近检查时间保存在插件本地存储中，用于恢复偏好、离线搜索和控制更新频率。
复制的链接与安装提示
只有你点击复制按钮时，插件才把仓库链接或生成的安装提示写入系统剪贴板。插件不读取剪贴板，也不会自动发送内容给 AI 服务或执行安装。你随后粘贴内容到其他应用时，由你选择的应用处理这些内容。

网络请求与第三方服务

公开目录更新

插件在首次打开、打开时距上次成功检查超过 24 小时，或你手动刷新时，通过 HTTPS 请求 https://agentskills.media/data/discovery_index.json。请求不附带搜索词、收藏、选中文字或浏览器 Cookie。没有网络时，仍可使用已缓存或内置的目录。

与其他网站请求一样，服务网站的托管及网络基础设施会接收到 IP 地址、请求时间、请求路径、浏览器请求头等连接信息，并可能为提供服务、安全或故障排查保留访问日志。官网通过 GitHub Pages 发布；相关基础设施的数据处理适用其服务政策，包括 GitHub 隐私声明。本项目没有为这些基础设施日志设定或承诺统一的保留期限。

你主动访问的链接

点击仓库、README、官网或反馈链接时，浏览器会访问相应网站，该网站会按自身政策接收请求信息。插件不读取你在 ChatGPT、其他 AI 工具或其他浏览器扩展中的对话。

插件权限分别用于什么

storage
保存本地目录缓存、收藏、语言与主题设置，以及临时搜索状态。
sidePanel
在 Chrome 侧边栏展示搜索助手。
contextMenus
提供“搜索选中文字”的右键菜单；只有主动点击菜单时才使用选中的文字。
https://agentskills.media/*
允许从官网获取最新公开目录。插件未申请读取浏览历史、Cookie、任意网站正文或剪贴板内容的权限。

官网的数据处理

官网通过浏览器 localStorage 保存界面语言、主题、列表视图与官网收藏。搜索与筛选在浏览器中进行，不发送到收藏数据库。未登录时，收藏只保存在本机。

可选的 GitHub 登录与云收藏

站点配置 Supabase 后，你可主动选择 GitHub 登录。GitHub 向 Supabase 提供用于识别账号的资料，例如 GitHub 用户标识、用户名、头像及认证所需的邮箱信息；Supabase 处理登录会话。网站在浏览器中保存会话凭据与按账号隔离的收藏缓存、待同步操作，以便恢复登录和离线使用。首次登录会合并此前的本地收藏，登录后的新增与取消收藏会同步到该账号的云端记录。站内收藏不会自动修改 GitHub Stars，也不需要读取或修改你的仓库代码。

云端收藏由所配置的 Supabase 项目保存，包括账号标识、仓库标识、用于显示收藏的公开仓库资料、删除标记及服务器更新时间。数据库访问规则限制普通用户只能读写自己的记录；这不是端到端加密存储，项目维护者可为运行服务、故障排查和处理删除请求管理云端记录。Supabase 与 GitHub 会接收登录和同步所需的连接信息，其处理分别适用 Supabase 隐私政策与前述 GitHub 隐私声明。清理本机数据或退出登录不删除已同步的云收藏。

官网排行榜展示今日访问次数（PV）和累计访客人数（UV），插件本身不包含该统计。在 https://agentskills.media 或 https://jaychempan.github.io/Agent-Leaderboard/ 加载排行榜时，向 soxft/busuanzi 公共服务的 https://busuanzi.9420.ltd/api 发送一次请求，两域名使用统一的统计命名空间。请求使用北京时间日期组成的虚拟统计路径，汇总每日页面加载量；累计访客人数由服务端去重，并非实名人数。切换榜单、筛选和语言不会再次计数。服务商根据 IP、浏览器 User-Agent 和签名匿名标识识别访客；签名标识保存在浏览器 localStorage 的 st_visit_identity_v1，随统计请求发送，清理存储或更换设备可能影响去重。

访问统计请求仅包含规范站点地址、统计日期与匿名标识，Referer 仅包含网站来源，不发送搜索词、查询参数、收藏、访问前的来源页面或第三方 Cookie。服务商会接收 IP、浏览器请求头等连接信息，其开源实现以哈希处理统计标识；公共服务没有 SLA 或数据完整性保证，本项目不承诺其数据保留期限。旧统计服务的数据没有迁移。通过项目本地预览服务器运行时，只向本机 /api/visits 上报，在本地数据库保存每日访问量和匿名浏览器标识；本地标识保存在 st_local_visit_id，不发送到第三方，也不记录 IP。其他预览域名不启用统计。

本隐私政策页面不加载访问计数、外部字体或第三方脚本；访问页面本身仍会产生前述网站托管请求。官网“复制示例安装提示”只写入你主动复制的内容，不会自动联系 AI 服务。

数据保留、控制与删除

  • 插件收藏：再次点击仓库书签即可取消收藏，并从插件本地收藏中移除该记录。
  • 临时搜索：清空搜索或更改筛选会更新当前会话状态。关闭单个侧边栏不一定清除会话存储；浏览器会在浏览器重启、扩展重新加载、禁用或更新时清除扩展会话存储。
  • 插件全部本地数据：卸载插件会移除其浏览器存储中的收藏、设置和目录缓存。浏览器自身的历史记录、标签页地址、系统剪贴板或已复制到其他应用的内容需在相应位置另行清理。
  • 网站云收藏：登录后取消收藏会同步删除标记，其他设备据此移除收藏。删除标记保留仓库标识和更新时间，防止旧设备恢复已取消的收藏；它不是数据库记录的永久物理删除。离线取消收藏需在恢复连接且同步成功后才会影响云端。
  • 官网本地数据与退出：清除相应网站来源的数据，可删除该来源保存的偏好、登录会话、收藏缓存与尚未同步的操作。退出登录或清除本机数据不会删除已同步的云记录，再次登录可恢复这些收藏；清除未上传的操作会造成这些操作丢失。
  • 永久删除云数据：可联系维护者请求永久清除云收藏或删除站内账号。删除 Supabase 中的账号会级联删除其收藏行。GitHub 授权可在 GitHub 应用设置中管理，撤销授权本身不会删除已有云数据；不要在公开 Issue 中提交令牌、密码或收藏明细。
  • 保留期限：插件收藏和设置保留至你移除数据或卸载插件，目录缓存可能在更新时被替换。网站已同步收藏与删除标记保留至相关云数据或账号被永久删除；备份及基础设施日志的保留取决于项目和服务设置。搜索词不保存在云收藏数据库中。

目录更新使用 HTTPS。浏览器本地存储由你的浏览器和设备保护，插件没有为本地缓存额外提供独立的加密或云端备份服务。

数据使用承诺

我们仅为本政策说明的搜索、筛选、收藏、设置与目录更新功能处理插件数据，不出售用户数据，不将其用于个性化广告、数据交易、信用评估或贷款用途。插件不上传浏览器中的搜索内容或收藏。网站可选的账号资料与云收藏仅用于登录、收藏同步及相关服务运维和删除请求。

Agent Leaderboard 对通过 Chrome 扩展 API 获取的信息的使用遵守 Chrome Web Store User Data Policy，包括 Limited Use（有限使用）要求。本插件不使用 Google 账户登录，也不请求访问 Google 账户数据。

政策更新与联系方式

若功能或数据处理方式发生变化，我们会更新本页面及顶部日期，并按适用的平台要求说明相关变更。

如有隐私问题或希望报告与本政策不一致的行为，请通过 项目 GitHub Issues 联系维护者。Issues 是公开页面，请勿提交密码、密钥或其他敏感信息。你主动提交的反馈会由 GitHub 按其隐私政策保存，维护者仅将其用于处理你的反馈。

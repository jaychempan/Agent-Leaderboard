隐私政策

生效及更新日期：2026 年 10 月 9 日 · 适用插件版本：1.6.0

这份政策说明 Agent Leaderboard 如何处理你使用 Chrome 搜索助手和官网时涉及的数据。

插件的搜索与筛选在你的设备上完成，收藏保存在当前浏览器。无需注册账号。插件不向开发者上传搜索词或收藏，不读取浏览历史、Cookie 或整页正文，也不包含广告或分析追踪代码。目录更新会产生必要的网络请求。

适用范围

本政策适用于由 Jiancheng Pan（GitHub：jaychempan）维护的 Agent Leaderboard Chrome 插件，以及 agentskills.media 官网。插件用于搜索、筛选、收藏公开的 AI 工具仓库，并复制仓库链接和安装提示。

插件与官网使用各自的浏览器存储，收藏不会在两者之间或不同设备之间同步。你主动打开的 GitHub 仓库、其他外部网站和 AI 编程服务，适用各自的隐私政策。

插件在本地处理什么

搜索词、筛选条件和主动选择的文字
你在插件或地址栏中输入的搜索词，以及主动使用右键搜索时选中的文字，仅用于本地目录检索。插件不自动扫描网页。当前搜索与筛选状态保存在浏览器会话存储中；右键请求在接收后移除，不发送到搜索服务器。地址栏搜索或备用搜索页面可能将关键词放在本地 chrome-extension:// 页面地址中。
收藏的仓库
仓库标识及收藏时的公开仓库资料保存在插件本地存储中，以显示收藏列表；没有开发者端的收藏账户或云同步。
偏好设置和目录缓存
语言、主题、公开目录缓存与最近检查时间保存在插件本地存储中，用于恢复偏好、离线搜索和控制更新频率。
复制的链接与安装提示
只有你点击复制按钮时，插件才把仓库链接或生成的安装提示写入系统剪贴板。插件不读取剪贴板，也不会自动发送内容给 AI 服务或执行安装。你随后粘贴内容到其他应用时，由你选择的应用处理这些内容。

网络请求与第三方服务

公开目录更新

插件在首次打开、打开时距上次成功检查超过 24 小时，或你手动刷新时，通过 HTTPS 请求 https://agentskills.media/data/discovery_index.json。请求不附带搜索词、收藏、选中文字或浏览器 Cookie。没有网络时，仍可使用已缓存或内置的目录。

与其他网站请求一样，服务网站的托管及网络基础设施会接收到 IP 地址、请求时间、请求路径、浏览器请求头等连接信息，并可能为提供服务、安全或故障排查保留访问日志。官网通过 GitHub Pages 发布；相关基础设施的数据处理适用其服务政策，包括 GitHub 隐私声明。本项目没有为这些基础设施日志设定或承诺统一的保留期限。

你主动访问的链接

点击仓库、README、官网或反馈链接时，浏览器会访问相应网站，该网站会按自身政策接收请求信息。插件不读取你在 ChatGPT、其他 AI 工具或其他浏览器扩展中的对话。

插件权限分别用于什么

storage
保存本地目录缓存、收藏、语言与主题设置，以及临时搜索状态。
sidePanel
在 Chrome 侧边栏展示搜索助手。
contextMenus
提供“搜索选中文字”的右键菜单；只有主动点击菜单时才使用选中的文字。
https://agentskills.media/*
允许从官网获取最新公开目录。插件未申请读取浏览历史、Cookie、任意网站正文或剪贴板内容的权限。

官网的数据处理

官网通过浏览器 localStorage 保存界面语言、主题、列表视图与官网收藏。官网的仓库搜索与筛选在浏览器中进行，这些偏好和收藏不会作为账户数据上传。

官网排行榜包含访问次数统计，插件本身不包含该统计。排行榜会向 api.counterapi.dev 请求对应榜单的计数，用于显示访问总次数。请求路径包含榜单标识，不包含搜索词或收藏；CounterAPI 作为第三方会接收 IP 地址和浏览器请求头等常规连接信息，并依其服务政策处理。

本隐私政策页面不加载访问计数、外部字体或第三方脚本；访问页面本身仍会产生前述网站托管请求。官网“复制示例安装提示”只写入你主动复制的内容，不会自动联系 AI 服务。

数据保留、控制与删除

  • 收藏：再次点击仓库书签即可取消收藏，并从插件本地收藏中移除该记录。
  • 临时搜索：清空搜索或更改筛选会更新当前会话状态。关闭单个侧边栏不一定清除会话存储；浏览器会在浏览器重启、扩展重新加载、禁用或更新时清除扩展会话存储。
  • 插件全部本地数据：卸载插件会移除其浏览器存储中的收藏、设置和目录缓存。浏览器自身的历史记录、标签页地址、系统剪贴板或已复制到其他应用的内容需在相应位置另行清理。
  • 官网本地数据：在浏览器中清除 agentskills.media 的网站数据，可删除官网保存的偏好和收藏。
  • 保留期限：插件收藏和设置持续保留，直到你移除相关数据或卸载插件；目录缓存可能在更新时被替换。开发者没有保存搜索词或收藏的服务器副本。

目录更新使用 HTTPS。浏览器本地存储由你的浏览器和设备保护，插件没有为本地缓存额外提供独立的加密或云端备份服务。

数据使用承诺

我们仅为本政策说明的搜索、筛选、收藏、设置与目录更新功能处理插件数据，不出售用户数据，不将其用于个性化广告、数据交易、信用评估或贷款用途。开发者不远程查看保存在你浏览器中的搜索内容或收藏。

Agent Leaderboard 对通过 Chrome 扩展 API 获取的信息的使用遵守 Chrome Web Store User Data Policy，包括 Limited Use（有限使用）要求。本插件不使用 Google 账户登录，也不请求访问 Google 账户数据。

政策更新与联系方式

若功能或数据处理方式发生变化，我们会更新本页面及顶部日期，并按适用的平台要求说明相关变更。

如有隐私问题或希望报告与本政策不一致的行为，请通过 项目 GitHub Issues 联系维护者。Issues 是公开页面，请勿提交密码、密钥或其他敏感信息。你主动提交的反馈会由 GitHub 按其隐私政策保存，维护者仅将其用于处理你的反馈。

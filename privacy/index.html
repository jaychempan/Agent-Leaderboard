隐私政策

生效及更新日期：2026 年 11 月 1 日 · 适用插件版本：1.7.5（1.6 仅本地收藏）

这份政策说明 Agent Leaderboard 如何处理你使用 Chrome 搜索助手和官网时涉及的数据。

搜索与筛选在你的设备上完成，未登录的收藏保存在本地；官网已登录时，插件可自动同步收藏。v1.7.5 使用已有官网登录时，会自动连接并合并插件本地收藏；手动退出插件可关闭自动连接。账号同步会将收藏的仓库标识和公开资料发送到 Cloudflare Worker 与 D1；不上传搜索词或选中文字。无需账号也可搜索和本地收藏。插件不读取浏览历史、Cookie 或整页正文，不包含广告或分析追踪代码。目录更新会产生必要的网络请求。

适用范围

本政策适用于由 Jiancheng Pan（GitHub：jaychempan）维护的 Agent Leaderboard Chrome 插件，以及 agentskills.media 官网。插件用于搜索、筛选、收藏公开的 AI 工具仓库，并复制仓库链接和安装提示。

插件与官网使用各自的本地存储和登录会话。v1.7.5 插件在官网已有有效登录时自动连接后，同一 GitHub 账号可通过同一个 Cloudflare Worker 和 D1 同步收藏；未登录时两端的本地收藏互相独立。你主动打开的 GitHub 仓库、其他外部网站和 AI 编程服务，适用各自的隐私政策。

插件在本地处理什么

搜索词、筛选条件和主动选择的文字
你在插件或地址栏中输入的搜索词，以及主动使用右键搜索时选中的文字，仅用于本地目录检索。插件不自动扫描网页。当前搜索与筛选状态保存在浏览器会话存储中；右键请求在接收后移除，不发送到搜索服务器。地址栏搜索或备用搜索页面可能将关键词放在本地 chrome-extension:// 页面地址中。
收藏的仓库
未登录时，仓库标识及收藏时的公开资料保存在插件本地存储中。首次连接账号会将已有本地收藏合并到当前账号；使用稳定仓库 ID 和导入回执去重，不会把前一个账号的云收藏导入另一个账号。缺少 ID 且无法解析的旧收藏继续留在本地，并显示待导入数量。账号收藏和移出目录仓库的快照保存在 D1，插件仅在当前浏览器会话内缓存账号列表，不保存持久账号镜像。本地导入去重记录可能包含原本地收藏快照、归属账号和分批导入/清理回执；这些记录可能在退出后保留，用于恢复导入并避免重复或账号混入。
官网账号与插件自动同步
v1.7.5 在官网已登录且使用插件时，可自动连接并合并本地收藏，无需跳转或再次确认。官网主页向正式插件建立原生消息通道，仅传公开账号标识、用户名与绑定 PKCE 的 90 秒一次性码；不传网站会话令牌或校验私钥。通道在已登录时发送轻量状态消息，并在断开后受控重连，不附带搜索或收藏内容。插件校验来源、端口、标签页、目标账号及状态后建立独立会话。插件自己的本站会话令牌保存在仅限受信任扩展上下文访问的 chrome.storage.local，新会话固定有效 30 天，不随访问延长。PKCE 等待数据和账号收藏缓存仍仅在 chrome.storage.session，不保存持久云收藏镜像。手动退出插件后，本地保存关闭自动连接的偏好，直到你再次选择同步。两端退出独立，不删除云收藏。无需 Google 账号、identity、Cookie 读取或仓库权限。
偏好设置和目录缓存
语言、主题、自动连接开关、公开目录与趋势缓存、最近检查时间保存在插件本地存储中，用于恢复偏好、离线搜索与趋势查看，以及控制更新频率。
复制的链接与安装提示
只有你点击复制按钮时，插件才把仓库链接或生成的安装提示写入系统剪贴板。插件不读取剪贴板，也不会自动发送内容给 AI 服务或执行安装。你随后粘贴内容到其他应用时，由你选择的应用处理这些内容。

网络请求与第三方服务

公开目录与趋势更新

插件在首次打开、打开时距上次成功检查超过 24 小时，或你手动刷新时，通过 HTTPS 请求 https://agentskills.media/data/discovery_index.json 和 https://agentskills.media/data/trends.json。请求不附带搜索词、收藏、选中文字或浏览器 Cookie。没有网络时，仍可使用已缓存或内置的目录与趋势快照。

与其他网站请求一样，服务网站的托管及网络基础设施会接收到 IP 地址、请求时间、请求路径、浏览器请求头等连接信息，并可能为提供服务、安全或故障排查保留访问日志。官网静态页面通过 GitHub Pages 发布，DNS 由腾讯云管理，独立的登录收藏 API 在 Cloudflare Workers 运行；相关基础设施的数据处理适用其服务政策，包括 GitHub 隐私声明。本项目没有为这些基础设施日志设定或承诺统一的保留期限。

你主动启用的登录与云收藏

v1.7.5 插件在官网已有登录或你选择登录后，通过普通官网页面完成 GitHub 授权，再由 https://agent-leaderboard-api.jaychempan.workers.dev 用绑定 PKCE 的一次性短期代码换取插件独立会话，并读取同一官网账号的收藏。添加和取消收藏会向该 API 发送仓库 ID、公开仓库快照和当前本站会话；首次导入还会发送去重标识。为导入缺少 ID 的旧收藏，插件会将保存的公开仓库名发送给 Worker，由 Worker 查询 GitHub 公开仓库接口解析名称和 ID；仅获取公开元数据，不申请额外仓库权限或访问私有代码。搜索词、筛选条件、选中文字和网页正文不发送到收藏 API。普通登录只获取 GitHub 标识、用户名及公开头像，不申请读取仓库代码、Gist 或邮箱的权限。本站会话与 GitHub token 不放进网址；登录跳转期间 Worker 会使用短期 HttpOnly Cookie 校验流程，插件不读取 Cookie。

官网和插件的已登录改动通过在线 API 保存；失败会恢复原状态并提示重试，不排队离线写入。重新同步会读取其他设备成功保存的改动。Cloudflare D1 中的收藏不会随标签页关闭、插件退出、卸载或会话过期而删除。

你主动访问的链接

点击仓库、README、官网或反馈链接时，浏览器会访问相应网站，该网站会按自身政策接收请求信息。插件不读取你在 ChatGPT、其他 AI 工具或其他浏览器扩展中的对话。

sidePanel
在 Chrome 侧边栏展示搜索助手。
contextMenus
提供“搜索选中文字”的右键菜单；只有主动点击菜单时才使用选中的文字。
https://agent-leaderboard-api.jaychempan.workers.dev/*
用于可选 GitHub 登录交换、首次导入，以及当前账号的收藏读取、添加、取消和退出。扩展的 connect-src 只允许所需目录和 API 来源，不加载远程执行代码。
https://agentskills.media/*
允许从官网获取最新公开目录和趋势快照。插件未申请读取浏览历史、Cookie、任意网站正文或剪贴板内容的权限。

官网的数据处理

官网通过浏览器 localStorage 保存界面语言、主题、列表视图与官网收藏。搜索与筛选在浏览器中进行，不发送到收藏数据库。未登录时，收藏只保存在本机。

可选的 GitHub 登录与云收藏

站点配置云服务后，你可主动选择 GitHub 登录。Worker 通过 GitHub 获取用户标识、用户名和公开头像/资料地址，用于识别账号；普通登录不申请仓库、Gist 或邮箱读取权限。GitHub access token 仅由 Worker 用于读取身份，随后丢弃，不发送到官网前端。登录跳转使用短期、一次性且绑定浏览器校验的数据交换本站会话；GitHub 令牌和本站会话令牌不会放进网址。浏览器在本站 localStorage 中持久保存随机的本站会话令牌；新会话固定有效 30 天，不随访问延长。关闭标签页、重启浏览器或刷新页面不会退出登录；同一网站来源的标签页通过存储事件同步登录切换与退出。OAuth 的 PKCE 校验等待数据仍仅保存在当前标签页的 sessionStorage。API 请求使用该会话令牌，不依赖第三方 Cookie；登录跳转期间 Worker 会使用短期 HttpOnly Cookie 校验流程。首次登录会合并此前的本地收藏，登录后的添加与取消通过在线 API 保存到当前账号。请求失败时恢复原状态并提示重试，不提供离线修改的后台排队上传。站内收藏不会自动修改 GitHub Stars，也不需要读取或修改你的仓库代码。

Cloudflare D1 保存账号标识、公开账号资料、站点会话令牌的哈希、登录流程的短期校验记录、本地导入的去重标识，以及仓库标识、收藏时的公开仓库资料和时间。Worker 根据当前会话限制用户只能读写自己的收藏；已登录的收藏列表仅保留在当前页面内存中，重新打开页面需要联网读取。浏览器 localStorage 保留本站登录凭据、匿名收藏、旧数据备份和首次导入记录，不保存账号云收藏镜像；短期登录校验数据保存在 sessionStorage。此服务不是端到端加密存储，维护者可为运行服务、故障排查和处理删除请求管理云端记录。Cloudflare 与 GitHub 接收登录和请求所需的连接信息，其处理分别适用 Cloudflare 隐私政策和前述 GitHub 隐私声明。暂时断网或服务错误会保留登录凭据和已知账号，并显示离线或重试状态。主动退出会清除或标记退出本地凭据，并在 API 可达时撤销当前会话；清理本机数据不会删除已保存的云收藏。

官网排行榜展示今日访问次数（PV）和累计访客人数（UV），插件本身不包含该统计。在 https://agentskills.media 或 https://jaychempan.github.io/Agent-Leaderboard/ 加载排行榜时，向 soxft/busuanzi 公共服务的 https://busuanzi.9420.ltd/api 发送一次请求，两域名使用统一的统计命名空间。请求使用北京时间日期组成的虚拟统计路径，汇总每日页面加载量；累计访客人数由服务端去重，并非实名人数。切换榜单、筛选和语言不会再次计数。服务商根据 IP、浏览器 User-Agent 和签名匿名标识识别访客；签名标识保存在浏览器 localStorage 的 st_visit_identity_v1，随统计请求发送，清理存储或更换设备可能影响去重。

访问统计请求仅包含规范站点地址、统计日期与匿名标识，Referer 仅包含网站来源，不发送搜索词、查询参数、收藏、访问前的来源页面或第三方 Cookie。服务商会接收 IP、浏览器请求头等连接信息，其开源实现以哈希处理统计标识；公共服务没有 SLA 或数据完整性保证，本项目不承诺其数据保留期限。旧统计服务的数据没有迁移。通过项目本地预览服务器运行时，只向本机 /api/visits 上报，在本地数据库保存每日访问量和匿名浏览器标识；本地标识保存在 st_local_visit_id，不发送到第三方，也不记录 IP。其他预览域名不启用统计。

本隐私政策页面不加载访问计数、外部字体或第三方脚本；访问页面本身仍会产生前述网站托管请求。官网“复制示例安装提示”只写入你主动复制的内容，不会自动联系 AI 服务。

数据保留、控制与删除

  • 插件收藏：未登录时再次点击书签，从插件本地收藏中移除记录。登录后取消收藏会通过 API 删除当前账号的 D1 记录；其他设备或官网重新同步后看到变化。失败会回滚，不会排队离线删除。无法解析而尚未导入的旧收藏仍需在本地管理。
  • 临时搜索：清空搜索或更改筛选会更新当前会话状态。关闭单个侧边栏不一定清除会话存储；浏览器会在浏览器重启、扩展重新加载、禁用或更新时清除扩展会话存储。
  • 插件退出与卸载：主动退出会清除或标记退出插件的本地登录凭据、清除账号缓存，并在 API 可达时撤销当前插件会话；自动连接保持关闭，直到再次选择同步。它不退出官网的独立会话，也不删除云收藏。关闭侧边栏、重启浏览器或重载、更新插件不会清除持久登录凭据。卸载会移除插件本地收藏、设置、目录缓存和登录凭据；尚未成功导入的本地收藏会丢失，已保存的云收藏可再次登录恢复。浏览器自身的历史记录、标签页地址、系统剪贴板或已复制到其他应用的内容需在相应位置另行清理。
  • 网站云收藏：登录后取消收藏会通过 API 删除 D1 中该账号对应的收藏记录；成功后其他设备重新读取收藏即可看到变化。请求失败时界面会恢复原状态并提示重试，离线操作不会在后台自动排队上传。
  • 官网本地数据与退出：清除相应网站来源的数据，可删除该来源的偏好、匿名收藏及备份、导入记录，以及 localStorage 中的本站登录凭据和 sessionStorage 中的登录校验数据。主动退出会清除或标记退出本地凭据，并在 API 可达时撤销当前会话；同来源的其他官网标签页会同步退出。首次导入成功前清除本地数据，会丢失尚未上传的本地收藏。退出登录或清除本机数据不会删除已成功保存的云收藏，再次登录可恢复这些收藏。
  • 永久删除云数据：可联系维护者请求删除站内账号、会话与全部云收藏。GitHub 授权可在 GitHub 应用设置中管理，撤销授权本身不会删除站点已有数据；不要在公开 Issue 中提交令牌、密码或收藏明细。
  • 保留期限：插件收藏和设置保留至你移除数据或卸载插件，目录缓存可能在更新时被替换。官网与插件共享的云收藏保留至你取消收藏或相关账号被删除；新本站登录会话固定有效 30 天，不滚动续期；旧八小时会话仍保留原到期时间，到期后可能需要再登录一次。清除本地登录数据、会话到期或服务端撤销后需要重新登录。官网与插件持有各自的持久登录凭据；账号收藏缓存仍只在网页内存或插件 chrome.storage.session 中，不是长期备份。备份及基础设施日志的保留取决于项目和服务设置，数据库删除不代表基础设施备份即时清除。搜索词不保存在云收藏数据库中。

目录更新使用 HTTPS。浏览器本地存储由你的浏览器和设备保护，插件没有为本地缓存额外提供独立的加密或云端备份服务。

数据使用承诺

我们仅为本政策说明的搜索、筛选、收藏、设置与目录更新功能处理插件数据，不出售用户数据，不将其用于个性化广告、数据交易、信用评估或贷款用途。插件不上传浏览器中的搜索内容或选中文字。仅在你主动登录时，插件与官网向同一服务发送账号身份、收藏仓库标识与公开资料，用于登录、收藏同步及相关服务运维和删除请求。

Agent Leaderboard 对通过 Chrome 扩展 API 获取的信息的使用遵守 Chrome Web Store User Data Policy，包括 Limited Use（有限使用）要求。本插件不使用 Google 账户登录，也不请求访问 Google 账户数据。

政策更新与联系方式

若功能或数据处理方式发生变化，我们会更新本页面及顶部日期，并按适用的平台要求说明相关变更。

如有隐私问题或希望报告与本政策不一致的行为，请通过 项目 GitHub Issues 联系维护者。Issues 是公开页面，请勿提交密码、密钥或其他敏感信息。你主动提交的反馈会由 GitHub 按其隐私政策保存，维护者仅将其用于处理你的反馈。

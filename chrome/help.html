Agent 搜索助手 · 使用说明

English

随手搜索，留在当前网页

点击工具栏插件图标打开侧边栏。快捷键为 Windows / Linux 的 Ctrl+Shift+Y、macOS 的 Command+Shift+Y；如有冲突，可在 chrome://extensions/shortcuts 中修改。

选中网页上的文字，右键选择“在 Agent 排行榜搜索”。也可在地址栏输入 agent，按 Tab 或空格，再输入关键词并回车，在新页面内查看结果。

搜索与收藏

点击搜索栏右上角的 EN 切换英文，点击“中”返回中文。语言选择保存在当前 Chrome 配置中，并同步到已打开的插件页面。切换时保留搜索、筛选、收藏与当前页码；仓库名称和简介保留原文。

仓库按每页 30 条分页，底部固定显示上一页、页码和下一页。可输入页码按回车直接跳转；翻页后回到列表顶部，搜索、筛选或排序变化时回到第一页。

顶部集中搜索和筛选，仓库列表单独滚动，底部显示数据状态。名称、Stars 和书签收藏同一行，简介显示一行，作者、语言、所属榜单和 README 位于下方。点击“详情”可查看完整简介和所有标签。顶部六个榜单入口全部直接显示，用图标和简短名称区分，不需要横向滚动。仓库左侧也显示对应的彩色图标与类型文字，便于区分 Skills、MCP、Prompt、框架和研究工具。分类和用途并排显示。

按仓库名、描述、用途、标签搜索；多个关键词用空格分隔，结果需同时包含这些关键词。榜单名称和二级分类与网站一致：先选榜单，再选 Claude、Codex、数据库、流程编排等分类。

用途标签可多选，结果需同时满足全部已选用途。标签数字是应用其他筛选后、应用用途筛选前的仓库数，与网站逻辑一致。点击“全部用途”展开双列选项，可查找用途、清空已选，按 Esc 收起；也可点击仓库卡片上的分类或用途快速筛选。

更多筛选包括平台、语言、最低 Stars，以及近 1 月 / 近 3 月 / 近 1 年。可逐项移除已选条件。切换榜单会清除原有分类和用途。按相关度、Stars 或最近更新排序。

同一仓库会合并显示，保留所有所属榜单。平台来自目录关键词推断，请以仓库 README 的兼容说明为准。“最近更新”使用目录中的 GitHub updated_at，并不等同于最近一次代码提交。

点击仓库右侧的书签按钮收藏；点击“详情”查看用途、标签和链接。未登录时收藏保存在当前 Chrome 配置中。v1.7.5 可在“收藏”页选择 GitHub 登录，与官网和其他设备的同一账号共享云收藏。即使仓库从后续目录移除，仍保留收藏时的信息。

按 / 聚焦搜索框；在搜索框按 Esc 清空关键词。主题默认跟随系统明暗模式；主题按钮依次切换“跟随系统、浅色、深色”，选择会记住。底部网站链接会打开对应榜单。

趋势榜（v1.7.5）

切换“趋势”，选择 Skills、MCP、Prompt、框架或研究板块，再选日榜、周榜、月榜。可按增长率或新增 Stars 查看前 20 名，并用顶部搜索缩小范围。趋势页独立排序，不应用发现页的分类和高级筛选；仍可收藏仓库、查看详情和复制安装提示。

趋势与官网使用相同的每日快照，显示实际起止日期。新增 Stars 为期末减期初，增长率为新增除以期初 Stars；榜单只展示正增长，期初为零的项目不参与增长率排序。历史不足会提示，不会按零增长处理。插件内置离线趋势，随目录更新；这些数据反映站内观测变化，并非 GitHub 实时新增。

GitHub 登录与云收藏（v1.7.5）

官网页面已经登录时，打开插件“收藏”即可直接同步，不跳转、不打开新标签页，也不需要确认连接。没有官网登录时，点击“同步网页版收藏”直接打开官网收藏弹窗，在弹窗内完成 GitHub 登录后自动同步。升级前已打开的旧官网页需手动刷新一次。插件读取同一官网账号已保存的收藏；不需要填写密钥，也不会修改 GitHub Stars 或申请仓库权限。首次登录合并已有本地收藏，切换账号不会导入上一个账号的云收藏。缺少仓库 ID 且已删除或无法解析的旧收藏仍留在本地，并显示待导入数量。

登录后的收藏添加和取消需联网，失败会恢复原状态并提示重试，不会排队离线修改。点击同步可读取官网或其他设备的最新收藏。移出目录的仓库保留收藏快照。插件在仅限可信扩展上下文的 chrome.storage.local 保存本站登录凭据，新登录固定有效 30 天；账号缓存和 PKCE 校验数据仍只在 chrome.storage.session，不保存 GitHub 令牌或持久云收藏镜像。重启浏览器或重载、升级插件后可恢复登录，短暂断网也不会清除凭据。旧八小时会话保持原期限，到期后再登录一次即可使用新期限。退出会撤销当前插件会话并关闭自动连接，直到你再次点击“同步网页版收藏”；不会删除云收藏或退出官网；用于去重和恢复导入的原本地收藏快照、账号归属及导入回执可能继续保留在本地。

复制给 AI 安装

点击仓库右侧、书签旁的复制图标，或展开“详情”点击“复制安装提示”，再粘贴到 Claude Code、Codex、Cursor 等 AI 编程工具。内容包含仓库与 README 地址，让 AI 先识别当前环境和项目类型，再按官方文档安装、保留已有配置并验证。资源合集会先确认具体组件；不支持直接接入的项目会说明实际用法。复制内容跟随界面语言，插件不会自动安装或发送给其他应用。

数据和隐私

插件内置构建时的目录和趋势快照。打开时如果距离上次成功检查超过 24 小时，会从 agentskills.media 下载最新 JSON 目录与趋势；也可点击“更新数据”。更新失败时继续使用本地数据，显示实际观测日期。

搜索与筛选均在本地完成。插件不读取网页正文、浏览历史或 Cookie，不含分析追踪代码。只有主动使用右键搜索时，所选文字才会传入插件，并且不发送到搜索服务器。打开仓库、网站或 README 链接时，浏览器会正常访问对应网站。

storage 用于目录缓存、匿名收藏、设置和短期会话；sidePanel 用于侧边栏；contextMenus 用于右键搜索；普通官网标签页用于主动选择的登录连接，不需要 identity 或 Cookie 读取权限。agentskills.media 访问权限用于目录更新，agent-leaderboard-api.jaychempan.workers.dev 用于登录交换和云收藏读写。未登录不上传收藏；主动登录会把收藏仓库 ID 和公开资料按账号保存到 Cloudflare D1，不上传搜索词。缺少 ID 的旧收藏会由 Worker 查询 GitHub 公开仓库元数据解析名称和 ID，不申请额外仓库权限。卸载清除插件本地数据，不删除已保存的云收藏。
